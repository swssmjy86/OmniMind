## 1. 공식 이메일

**추천: 무료 Gmail 계정으로 시작, 수익 발생 후 커스텀 도메인으로 전환.**
Google Workspace(예: hello@omnimind.kr)는 월 비용이 들어 "월 고정비 0원" 원칙과 맞지 않는다.
지금 단계는 무료 Gmail로 충분하고, 나중에 언제든 전환 가능하다.

### 확정 계정
**공식 이메일: `omnimind.i6uj.official@gmail.com`** (2026-08-07 개설 완료)
웹 문의 페이지(`/contact`)·이메일 서명·다른 채널 복구 이메일 모두 이 주소로 통일한다.

### 개설 절차(기록용)
1. gmail.com → "계정 만들기" → "비즈니스용 계정"
2. 2단계 인증 설정(권장) — 카카오·인스타 등 다른 채널 계정 복구 이메일로도 쓰이므로 보안을 켜둔다
4. Gmail 설정 → 모든 설정 보기 → 일반 → 서명에 아래 서명 문구 등록

### 복사해서 쓰기 — 이메일 서명
```
온기를 담아,
옴니마인드 팀

모든 나를 잇다, 옴니마인드
https://omni-mind-i6uj.vercel.app  (커스텀 도메인 확보 시 교체)
```

> 서명 이미지가 필요하면 `docs/marketing/brand/wordmark.png`(가로형 로고)를 넣는다.

## 2. 카카오톡 채널

설계서 §6.3(알림)에 "1순위 카카오톡 채널"로 이미 계획되어 있다. 완전 무료.

### 개설 절차
1. center-pf.kakao.com(카카오톡 채널 관리자센터) → 카카오 계정으로 로그인
2. "새 채널 만들기" 클릭
3. 채널 이름: `옴니마인드`
4. 검색용 아이디(영문, 중복 확인 필요): `omnimind`
5. 카테고리: 라이프스타일 > 운세/사주
6. 프로필 사진 등록, 아래 소개글 입력
7. 개설 후 "채널 홈 관리"에서 소개 문구·대표 이미지 추가 편집 가능

### 복사해서 쓰기 — 채널 소개글
```
사주, MBTI, 혈액형, 별자리…
흩어져 있던 당신의 조각들을 하나로 이어드려요 🌿

매일 아침, 당신만을 위한 오늘의 기운을 전해드릴게요.
— 모든 나를 잇다, 옴니마인드
```

### 향후 연동 메모
앱의 §6.3 알림 설계(아침 7~8시 1회, 하루 1회 초과 금지)와 이 채널을 나중에 카카오 알림톡/친구톡으로
연결할 수 있다. 채널 개설은 지금 해두고, 실제 발송 연동은 별도 기능 작업으로 진행.

## 3. 인스타그램

§6.2 공유 카드 확산 전략("MBTI 콘텐츠 문법 활용")과 직접 연결되는 채널.

### 개설 절차
1. 위에서 만든 공식 Gmail로 인스타그램 새 계정 생성
2. 사용자명 후보(중복 확인 필요): `omnimind.official`, `omnimind_kr`
3. 프로필 → "프로페셔널 계정으로 전환" → "크리에이터" 선택(무료, 인사이트 확인 가능)
4. 프로필 사진: 로고/워드마크 (아래 참고)
5. 소개글(bio) 등록, 링크에 서비스 URL 연결

### 복사해서 쓰기 — 인스타그램 bio
```
🌙 모든 나를 잇다, 옴니마인드
사주 × MBTI × 혈액형 × 별자리
오늘의 기운을 가장 잘 아는 곳
👇 나의 조각 이어보기
```

### 복사해서 쓰기 — 첫 게시물 문구 초안
```
MBTI만으로는 반쪽짜리예요.
사주까지 이어야 진짜 나.

1,920가지 조합 중, 당신은 어떤 이야기일까요?
```

앱의 `/api/card` 공유 카드(§P4-1)를 그대로 게시물 이미지로 쓸 수 있다 — 온보딩 완료 후 나오는
"나의 조각 카드"를 캡처해 첫 게시물로 올리는 방식을 추천.

### 프로필 이미지(로고) 메모
공식 브랜드 마크가 준비됐다 → **`docs/marketing/brand/profile-mark.png`** 를 프로필 사진으로 사용한다.
원형 크롭에 맞춰 초승달을 중앙에 배치했으므로 인스타·카카오 원형 프로필에서 잘 읽힌다.
작은 사이즈가 필요하면 `profile-mark-320.png`.

## 4. 공식 로고 / 브랜드 마크

앱 아이콘과 동일한 얼굴을 모든 채널이 공유한다 — **딥그린 밤하늘 위 크림빛 초승달 + 코랄 별자리
("흩어진 나를 잇다")**. 브랜드 가이드(설계서 §5.2 베이지·코랄·딥그린, §5.3 달·별 모티프)에 부합.

| 파일 | 용도 |
|------|------|
| `brand/profile-mark.png` (1024, 원형 크롭 대응) | 인스타·카카오·이메일 프로필 사진 |
| `brand/profile-mark-320.png` (320) | 작은 프로필 슬롯 |
| `brand/wordmark.png` (가로형, 딥그린 글자·투명) | 밝은 배경용 로고 — 이메일 서명·문서 헤더·게시물 |
| `brand/wordmark-light.png` (가로형, 크림 글자·투명) | 어두운 배경용 로고 |
| 웹 favicon/PWA 아이콘 | `src/app/favicon.ico`·`icon.png`·`apple-icon.png`, `public/icon-512·192.png` (같은 마크로 통일) |

재생성: `swift docs/marketing/brand/make-brand-assets.swift profile <out>.png`
(워드마크는 `... wordmark <out>.png [dark|light]`). CoreGraphics 벡터라 언제든 동일하게 다시 뽑을 수 있다.

색상 값: 딥그린 `#2D5A4A`, 크림 `#F9F1E2`, 코랄 `#E8927C`, 나이트 `#12261F`.
